# Cut Log

`index.html` is the source of the Cut Log artifact published at
https://claude.ai/artifact/C1hYkSmQ4QEZqQkdzC1saE (page content only; the
Artifact tool adds the document skeleton at publish time).

- Edit `index.html`, then publish it with the Artifact tool using that `url`.
  Omit `capabilities` so the stored ones (db, sample with images, user) carry forward.
- Every time the artifact is updated, commit and push the same change here.
- If the artifact may have changed elsewhere, read it first and sync `index.html` before editing.
- Logged data lives in the artifact's database (`days/<date>`, `config/main`), not in this repo.
